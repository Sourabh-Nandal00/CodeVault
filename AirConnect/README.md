AirConnect – Airport Management System

AirConnect is a **Java-based console application** designed to simulate basic airport operations such as flight management, passenger registration, ticket booking, check-in, baggage security, and airport reports.
Features

* Add and view flights
* Register passengers
* Register airport staff
* Book flight tickets
* Automatic seat allocation
* Baggage fee calculation
* Passenger check-in
* Boarding pass generation
* Baggage security screening
* Flight status reports
* Airport operations and revenue reports

Technologies Used

* Java
* Java Collections
* `LocalDateTime` and `DateTimeFormatter`
* Java Streams
* Object-Oriented Programming concepts

How to Run

1. Make sure Java is installed on your system.
2. Clone or download this repository.
3. Open a terminal in the project folder.
4. Compile the program:

```bash
javac Airconnect.java
```

5. Run the program:

```bash
java Airconnect
```

Main Menu

The application provides options for:

1. Add Flight
2. List Flights
3. Register Passenger
4. Register Staff
5. Book Ticket
6. Check-in Passenger
7. View Passenger Tickets
8. Baggage Security Screening
9. Flight Status Report
10. Airport Operations Report
11. Exit
