# Snake Game in Java

A simple console-based Snake Game built using Java.

## Features
* Console-based gameplay
* W, A, S, D controls
* Randomly generated food
* Score tracking
* Collision detection
* 20 × 10 game board
* Q key to quit the game

## Controls

| Key | Action     |
| --- | ---------- |
| W   | Move Up    |
| A   | Move Left  |
| S   | Move Down  |
| D   | Move Right |
| Q   | Quit Game  |

## How to Play

1. Run the program.
2. Use W, A, S, or D to control the snake.
3. Eat the food represented by `*`.
4. The snake is represented by `#`.
5. Each food item increases the score by 1.
6. Avoid hitting the walls and the snake's own body.
7. Press Q to quit the game.

## Requirements

* Java Development Kit (JDK)
* Visual Studio Code (optional)
* Java Extension Pack for VS Code (optional)

## Run Using VS Code

1. Install Java JDK on your computer.
2. Install Visual Studio Code.
3. Install the Java Extension Pack from the VS Code Extensions marketplace.
4. Open the project folder in VS Code.
5. Open `SnakeGame.java`.
6. Click the `Run` button above the `main` method.

You can also run the program using the VS Code integrated terminal.

Open the terminal in VS Code:

```text
Terminal → New Terminal
```

Compile the program:

```bash
javac SnakeGame.java
```

Run the program:

```bash
java SnakeGame
```

## Run Using Command Prompt

Open Command Prompt in the project folder.

Compile:

```bash
javac SnakeGame.java
```

Run:

```bash
java SnakeGame
```
